## Problem Statement

Calculating final grades for students is a time-consuming task for teachers. They have to:
- Check each student's attendance
- Calculate total marks from different exams
- Apply pass/fail rules
- Compare students to give fair grades
- Do this for every student in the class

Doing this manually takes a lot of time and can lead to mistakes. Sometimes students might get wrong grades because of calculation errors.

This program solves this problem by doing all the calculations automatically. The teacher just needs to enter the marks, and the program does the rest.

## Who can use this
- School teachers
- College professors
- Tutoring centers
- Any educational institution

## Main Features
- Takes student marks and attendance
- Checks if student can take exams (attendance rule)
- Calculates total score
- Gives grades based on class performance
- Shows clear results for each student
